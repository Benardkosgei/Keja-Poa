# 8. 3D RECONSTRUCTION REQUIREMENTS (Open3D Pipeline)

* Take multiple images or depth images (if available)
* Create a point cloud (if possible)
* Create a mesh reconstruction (Poisson reconstruction)
* Simplify mesh for web usage
* Export results as `.ply`, `.obj`, or `.glb`
* Store outputs in server media folder

### Pipeline must include:

* Preprocessing
* Noise removal
* Downsampling
* Normal estimation
* Mesh generation
* Texture mapping (optional advanced)

Expose this as a Django background task endpoint:

* `/api/v1/tours/{tour_id}/reconstruct`

Even if full reconstruction is heavy, implement the architecture with job queues (Celery recommended), but provide fallback synchronous mode for MVP.
